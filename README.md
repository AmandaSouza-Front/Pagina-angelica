# 🔐 Página Profissional — Angélica Silva de Oliveira

Página profissional desenvolvida para **Angélica Silva de Oliveira**, com foco em **Cibersegurança, Proteção de Dados e Tecnologia**.

O projeto foi desenvolvido com uma proposta moderna, profissional e responsiva, apresentando informações sobre trajetória, habilidades e conhecimentos de forma organizada e acessível.

## 🚀 Tecnologias utilizadas

* HTML5
* CSS3
* JavaScript
* GitHub
* GitHub Pages

## 💻 Sobre o projeto

Este projeto foi desenvolvido por **Amanda Souza** como parte do meu portfólio de desenvolvimento web.

O objetivo foi criar uma página profissional com identidade visual moderna, navegação simples e adaptação para diferentes dispositivos.

## ✨ Destaques

* Design moderno e profissional
* Layout responsivo
* Navegação intuitiva
* Apresentação profissional
* Publicação na internet com GitHub Pages
